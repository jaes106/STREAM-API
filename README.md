# Java 8 Stream API – Use Cases

This repo demonstrates basic operations of the Java 8 Stream API, showing how to process collections using functional-style pipelines.

## UC 2.1 – forEach  
Create a stream from a collection and iterate through elements using `forEach`.

## UC 2.2 – map  
Transform each element in the stream (e.g., double the value) using `map`.

## UC 2.3 – collect  
Store processed stream elements into a new `List` using `collect`.

## UC 2.4 – filter  
Filter elements based on a condition (e.g., extract even numbers).

## UC 2.5 – findFirst  
Find the first element that matches a condition using `findFirst`.

## UC 2.6 – min & max  
Find the minimum and maximum elements in a stream.

## UC 2.7 – sum & average  
Calculate the total sum and average of numeric elements in a stream.

## UC 2.8 – allMatch & anyMatch  
Check whether all elements or at least one element matches a given condition.

## UC 2.9 – sorted  
Sort stream elements in ascending order using `sorted`.
